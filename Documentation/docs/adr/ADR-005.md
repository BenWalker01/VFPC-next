# ADR-005 — Validation Scope for Controller Departure Lists

- **Decision status:** Accepted
- **Acceptance recorded:** 17 November 2026
- **Supersedes:** [ADR-003](ADR-003.md)
- **Implementation status:** Implemented in PR #42. Manual EuroScope
  Sweatbox verification passed for `SCO_CTR` and `EGPH_TWR`.
- **Verification:** [PR #42 DEP selection verification](../../reviews/PR-42-DEP-selection-verification.md)

## Context

ADR-003 used controller callsigns and UKCP position coverage to determine which airports were eligible for validation. The project owner requested removing this filtering and using the controller's selections instead.

EuroScope exposes the airport-level DEP selections in Runway Activity. VFPC uses those selections to determine which departure airports are in scope.

## Decision

Use EuroScope’s airport-level DEP selections in Runway Activity to determine which departure airports are in scope for automatic validation. Validate eligible IFR departures from those airports without filtering by controller callsign, position suffix or UKCP coverage. The same scope policy applies to local, approach, area and observer positions.

## Rationale and alternatives

Using Runway Activity as the source for validation scope lets VFPC follow airport selections already made in EuroScope.

## Consequences

- A selected airport can be validated even if it is outside a position's former
  UKCP coverage or another controller is responsible for it. The controller
  remains responsible for operational decisions.
- The UKCP scope lookup is no longer required. `.vfpc scope` reports the
  selection, and `.vfpc scope reload` refreshes Runway Activity.
